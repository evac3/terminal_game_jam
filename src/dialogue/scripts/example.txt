# --- Scene 3: tutorial ------------------------------------------
# Command steps use `input main [...]`: they only count when typed in the
# terminal (so the command really runs). Meanwhile the NPC screen shows
# "[ press 1 to go to the terminal ]".

npc: Let's get you started!
wait 800

# 3.1  cd: what a directory is
npc: cd stands for “change directory.” You can think of a directory like a folder.
npc: It contains other files, and sometimes other folders that can contain more files.
npc: Here’s a little example:
npc: home
npc: L user
npc:     L downloads
npc:     L applications
npc:     L documents
input [Enter]

# 3.2  cd: moving around
npc: You can use cd to go from a directory to a file/other directory within that directory, or .. to return to a previous directory.
input [Enter]
npc: For example, if you’re in the “user” directory, you can use “cd downloads” to move to the “downloads” directory, or “..” to go back to the “home” directory.
input [Enter]
npc: If you want to move through multiple directories at once, you can construct a path using “/.”
npc: For example, if you’re in the “documents” directory and want to go straight to “applications,” you can either use “cd ..” and “cd applications” or use “cd /home/user/applications” to go there in one command.
input [Enter]

# 3.3  player pushes back

# --- Scene 5: FIRST EVENT: word puzzle ----------------
# `event: word-puzzle` runs src/events/wordPuzzle: it puts puzzle.txt in
# the player's home folder. `view puzzle.txt` opens it in its own window.
# The answer must be typed on the NPC screen (`input npc [...]`). Each
# wrong answer gets the `wrong:` line(s) from the NPC.

npc: Wait. Something just landed in your home folder.

npc: It's a puzzle. Find it in your terminal and read it.
npc: When you know the answer, come back here (press 1) and tell me.

main: [new file: ~/puzzle.txt]

input npc [incident]
