npc: |  L user
npc: |     L downloads
npc: |     L applications
npc: |     L documents
input [Enter]
npc: You can use cd to go from a directory to a file/other directory within that directory, or .. to return to a previous directory. For example, if you’re in the “user” directory, you can use “cd downloads” to move to the “downloads” directory, or “..” to go back to the “home” directory. If you want to move through multiple directories at once, you can construct a path using “./.” For example, if you’re in the “documents” directory and want to go straight to “applications, you can either use “cd ..” and “cd applications” or use “cd home/user/applications” to go there in one command.
